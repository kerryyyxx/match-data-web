# 🔍 数据匹配工具（Excel VLOOKUP升级版）

## 这工具是干啥的？
就是一个在浏览器里运行的、比Excel VLOOKUP更好用的匹配工具。

**举个栗子🌰：**
- 你有一个**大表格**：全公司人员信息（姓名、手机号、身份证、部门...）
- 你有一个**小表格**：今天要联系的人（只有姓名）
- 这工具能自动从小表格里的姓名，去大表格里找到对应的手机号填上

## ✨ 有啥特点？
- ✅ **不用装任何软件**：打开浏览器就能用
- ✅ **界面简单**：三步走，傻子都会用
- ✅ **自动处理重名**：遇到两个“张三”会弹出来让你选
- ✅ **支持Excel和CSV**：直接上传就行

## 🚀 怎么用？
### 第一步：上传文件
- **大文件**：数据总表（啥都有的那个）
- **小文件**：待查询名单（要查的那批人）

### 第二步：设置匹配规则
- 大文件里用哪一列去查？（比如“姓名”）
- 大文件里要提取哪一列？（比如“手机号”）
- 小文件里哪一列是查询条件？（也是“姓名”）
- 结果存放到哪一列？（填个新列名）

### 第三步：处理重名（如果有的话）
- 遇到同名的人，工具会停下来让你选
- 会显示这俩人的其他信息（身份证、部门等）
- 选对了继续往下走

### 第四步：下载结果
- 匹配完直接下载Excel文件
- 小文件里多了一列，就是查到的结果
